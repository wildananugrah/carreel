Component breakdown

New files created vs existing files changed

✦ NEW FILES
hooks/useDamageDetector.ts

Loads EfficientDet-lite0 via tf.loadGraphModel(). Sets up a 1.5s interval during recording — each tick draws the video frame to a hidden 320×240 canvas, runs inference, filters results above a confidence threshold (0.4), and appends to a hintsRef. Returns { detections, isModelReady, getHints() }.

components/inspection/DamageDetectionOverlay.tsx

Absolutely-positioned SVG layer over the camera feed (pointer-events:none). Renders each detection as a rectangle with a label chip (Penyok / Goresan). Boxes fade out after 3s if not re-confirmed. Coordinates are scaled from model space (320×240) to display space.

public/models/efficientdet-lite0/

model.json + weight shards (~4.4 MB total). Populated by the one-time Keras training + tensorflowjs_converter step. Cached by browser after first load. Swap these files to upgrade the model — no code change needed.

scripts/train-damage-model/ (Python)

Standalone Python project (not part of the Bun app). Downloads CarDD dataset, fine-tunes EfficientDet-lite0 with Keras, converts output to TF.js format. Run once to produce the model files above. Documented README so anyone can retrain with new data later.

✎ CHANGED FILES
VideoRecorderOverlay.tsx

Add useDamageDetector(videoRef, isRecording). Mount <DamageDetectionOverlay> over the camera preview during recording only. Pass getHints() result up via onStop(blob, hints) callback. Hidden canvas element for frame capture added to DOM.

VideoReview.tsx

Accept hints from overlay's onStop. After chunked upload completes, include hints in the step completion PATCH request body.

schema.prisma + migration

Add tfDetectionHints Json? to InspectionStep. Non-breaking — null for all existing rows and for steps where detection was disabled.

prompts.ts — buildBodyInspectionPrompt

When hints are present, appends a "PRE-SCREENING HINTS" section to the system instruction: timestamps + damage class + confidence. Instructs Gemini to treat these as starting points, not ground truth.

step-analysis.job.ts

For BODY_INSPECTION steps, read step.tfDetectionHints from DB and pass to buildBodyInspectionPrompt. No change to video upload or Gemini call flow.

Feature flag

VITE_DAMAGE_DETECTION_ENABLED=true in .env. When false (default until model files exist), useDamageDetector returns empty detections immediately without loading TF.js at all — zero overhead on existing inspections.
